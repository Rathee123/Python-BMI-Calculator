# Python-BMI-Calculator 🐍
A simple BMI Calculator built using Python in Jupyter Notebook.

## 📌 Project Overview

The **BMI Calculator** is a beginner-friendly Python project developed using Jupyter Notebook. It calculates a person's Body Mass Index (BMI) based on their weight and height and identifies the corresponding BMI category.

This project demonstrates fundamental Python programming concepts through a simple, interactive calculation program.

## 🎯 Project Objectives

- Calculate Body Mass Index (BMI).
- Accept user input for weight and height.
- Identify BMI categories using conditional statements.
- Validate user inputs to prevent invalid calculations.
- Display BMI results in a clear and readable format.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Development Environment:** Jupyter Notebook

## 🧮 BMI Formula

BMI is calculated using the following formula:

`BMI = Weight (kg) / Height (m)²`

## 📊 BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25.0 – 29.9 | Overweight |
| 30.0 and above | Obese |

## ⚙️ Key Features

- User input for weight and height.
- Automatic BMI calculation.
- BMI category classification.
- Input validation for zero and negative values.
- Clear BMI report displaying the calculated result.

## 📚 Python Concepts Practiced

- Variables and Data Types
- User Input (`input()`)

- Arithmetic Operators
- Conditional Statements (`if`, `elif`, `else`)
- Logical Operators (`or`)

- Output Formatting

## ▶️ How to Run the Project

1. Clone or download this repository.
2. Open Jupyter Notebook.
3. Open `BMI_Calculator.ipynb`.
4. Run the notebook cells in order.
5. Enter your weight in kilograms and height in meters.
6. View your BMI result and category.
